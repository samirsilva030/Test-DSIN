TECNOLOGIAS UTILIZADAS
----------------------
Backend:
  - Java 21
  - Spring Boot 3.5 (Web, Data JPA, Validation)
  - H2 Database (memória)
  - Lombok
  - Arquitetura em camadas: Controller / Service / Repository (padrão MVC)
  - Detalhes em ARQUITETURA.md e CHECKLIST_EDITAL.md

Frontend:
  - HTML5, CSS3, JavaScript puro (sem framework)
  - Consumo da API REST via Fetch API
  - Separação em páginas: portal, cliente, admin-login, admin

Testes:
  - JUnit 5
  - Mockito (testes unitários de regras de negócio)
  - Spring Boot Test + MockMvc (testes de integração da API)

COMO RODAR O PROJETO
--------------------
Pré-requisitos: JDK 21 e Maven 3.8+

1. Abra o terminal na pasta do módulo:
   cd cabeleleila/cabeleleila

2. Execute a aplicação:
   mvn spring-boot:run

3. Acesse no navegador (obrigatório usar esta URL):
   http://localhost:8080

4. Para executar os testes automatizados:
   mvn test

IMPORTANTE: não abra os arquivos .html diretamente pelo Explorer (file://).
O frontend precisa do servidor Spring na porta 8080 para comunicar com a API.

ROTEIRO SUGERIDO PARA O VÍDEO
-----------------------------
1. Subir o sistema (mvn spring-boot:run)
2. Admin: login → cadastrar cliente → ver agendamentos
3. Cliente: cadastro → agendar 2 serviços → mostrar total
4. Cliente: alterar data (agendamento com +3 dias)
5. Cliente: histórico por período
6. Cliente: tentar alterar agendamento em menos de 2 dias → bloqueio
7. Rodar mvn test no terminal (opcional, reforça qualidade)

OBSERVAÇÕES FINAIS
------------------
- A regra dos 2 dias é validada no backend (AgendamentoService), não apenas na interface.
- O cliente identifica-se por e-mail; a sessão fica no localStorage do navegador.
- A sessão admin usa sessionStorage e token enviado no header X-Admin-Auth.
- Em produção recomenda-se: banco persistente (PostgreSQL), HTTPS, hash de senha e autenticação JWT.
